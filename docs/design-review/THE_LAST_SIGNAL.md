# The Last Signal — Fictional TV Profile Fixture

This fixture is an original, fictional work created only for UI design review. Its title, characters, creator, synopsis, seasons, episode titles, and artwork do not represent a real production. The artwork was generated specifically for this fixture and was prompted to avoid brands, existing franchises, copyrighted characters, and celebrity likenesses.

## Open the fixture

Run the development server, then open:

`http://localhost:5173/shows/show-design-review-the-last-signal`

Use the **Seasons** tab to review the season selector and episode-card layouts. The fixture includes two seasons and twelve episodes so wrapping, selection, metadata, synopsis truncation, and responsive behavior can be evaluated.

## Suggested design-review prompt

> This is a fictional TV-series profile used only as a UI design fixture. Please critique the visual hierarchy, spacing, typography, tab organization, season selection, episode-card density, artwork proportions, responsive risks, accessibility, and clarity. Focus on the interface design rather than the fictional story. Identify the three highest-impact improvements and explain why.
